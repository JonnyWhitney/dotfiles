# Extensions

## vim-mode

### Active mode

```
"extensions": ["/Users/jonathanloughlin/proj/PiExtentions/vim-mode"]
```

### Git mode

```
"packages": ["git:github.com/jonathanloughlin/vim-mode.git@v0.1.0"]
```

Swap by deleting one line and adding the other in `~/.pi/agent/settings.json`, then run `/reload`.
